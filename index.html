Describe a model, and get a complete Node.js REST API project: Express 5, MongoDB and Mongoose 9, with the connection string kept safely in .env.

Test your API

  1. Start the API: unzip the project, then npm install and npm run dev. Wait for Connected to MongoDB.
  2. In an API tester (for example Thunder Client in VS Code), create each request below in order. Choose the method, paste the URL, and for a body pick Body › raw › JSON. After request 1, copy the _id from the reply and use it where the URL says <id>.

Sample JSON to create records

Send POST once with each body below (Body › raw › JSON) to put some data in your database. Each one answers 201 with the saved record and its _id.
